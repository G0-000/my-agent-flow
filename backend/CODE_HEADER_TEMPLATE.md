在每个 Python 源文件的第一行添加以下文档字符串（示例为模板，按文件实际情况填写 <> 部分）：

"""
一、文件说明
- 职责：<一句话描述本文件的作用>

二、目录结构与位置
- 相对路径：<packages/.../module.py>
- 相邻/关联模块：<列出直接调用/被调用的模块>
- 所属子系统：<短期记忆/工具/持久化/长期记忆等>

三、主要类与函数（入参与返回）
- <ClassOrFuncA>(<params>) -> <return>
- <ClassOrFuncB>(<params>) -> <return>

四、典型调用链
- 入口：<从谁调用>
- 关键步骤：<校验/转换/调用外部/落库等>
- 出口：<返回给谁/产生何产物>

五、配置与环境变量
- MYAGENTFLOW_CONFIG_PATH：指向 config.local.yaml 或其他配置
- 其他：<例如模型 vendor、存储路径、端口等>

六、边界与注意事项
- 安全边界：<宿主路径守卫、审批门、配额/超时等>
- 失败语义：<出现异常时的行为与可恢复性>
- 性能与限制：<复杂度、批量/并发限制>
"""

使用说明：
- 仅为本阶段（ch01–ch05）改动过的 .py 文件补齐此注释；新增文件也需包含。
- 在提交前自检：文件首行是否能看到“ 一、文件说明 ”字样。
